# تصاویر وب‌سایت زر نور نیرو یکتا

تصاویر این پوشه برای بازطراحی لندینگ در تاریخ ۲۰۲۶-۰۹-۰۸ با هوش مصنوعی تولید شده‌اند. این‌ها **تصاویر مفهومی** هستند، نه عکس پروژه‌های اجراشده شرکت. به همین دلیل در متن جایگزین تصاویر نیز «مفهومی» ذکر شده و از آن‌ها به‌عنوان نمونه‌کار یا شاهد سابقه استفاده نشده است.

- `solar-farm.webp`: تصویر مفهومی نیروگاه خورشیدی در یک چشم‌انداز طبیعی.
- `power-grid.webp`: تصویر مفهومی دکل‌ها و شبکه انتقال برق.
- `electrical-engineering.webp`: تصویر مفهومی تجهیزات یک پست برق صنعتی.
- `og-cover.jpg`: تصویر ۱۲۰۰×۶۳۰ برای اشتراک‌گذاری صفحات عمومی، ساخته‌شده با تصویر خورشیدی و متن برند.

نسخه‌های `*-480.avif`، `*-800.avif` و `*-1264.avif` و WebPهای کوچک‌تر از منابع WebP بالا تولید می‌شوند. هدف، حذف تأخیر تولید تصویر در اولین بازدید و ارسال اندازه مناسب به موبایل است. بازتولید از ریشه مخزن، بعد از نصب وابستگی‌ها:

```bash
node scripts/optimize-landing-images.mjs
```

ابزار از `sharp` همراه Next.js استفاده می‌کند و وابستگی اجرایی جدیدی اضافه نشده است. تصاویر خام بزرگ و تصاویر جستجوشده در مخزن نگهداری نمی‌شوند.

برای انتشار نهایی، می‌توان این تصاویر را با عکس‌های واقعی دارای مجوز از پروژه‌های شرکت جایگزین کرد؛ هم‌زمان متن جایگزین و اندازه‌های responsive نیز به‌روزرسانی شوند.
