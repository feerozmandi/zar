# Vazirmatn

`vazirmatn-variable.woff2` کپی بدون تغییر فونت متغیر وزیرمتن از بسته `vazirmatn@33.0.3` است. نام فایل محلی بدون کروشه انتخاب شده است تا URL فونت در preload و CSS یکسان باشد و دانلود دوباره در Next.js اتفاق نیفتد.

منبع: https://github.com/rastikerdar/vazirmatn

مجوز: SIL Open Font License 1.1 — متن کامل در `OFL.txt`.

فونت با `next/font/local`، وزن‌های ۱۰۰ تا ۹۰۰، fallback تنظیم‌شده و `display: optional` بارگذاری می‌شود. در اتصال بسیار کند، فونت سیستم همان بازدید را بدون جابه‌جایی چیدمان نمایش می‌دهد؛ فونت سازمانی برای بازدید بعدی در کش قرار می‌گیرد.
