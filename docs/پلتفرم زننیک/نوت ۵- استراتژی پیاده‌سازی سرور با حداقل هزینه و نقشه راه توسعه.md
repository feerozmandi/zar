## 🚀 ۱. استراتژی استقرار روی سرور با حداقل هزینه اولیه (Low-Cost Infrastructure)

برای شروع فاز عملیاتی، نیازی به خریدهای سنگین سرور اختصاصی نیست. با زیرساخت زیر پروژه با **کمتر از ۲ تا ۳ میلیون تومان در ماه** با قابلیت مقیاس‌پذیری بالا (Scalable) اجرا می‌شود:

```
┌──────────────────────────────────────────────────────────┐
│              Cloudflare (Free CDN, SSL & WAF)            │
└────────────────────────────┬─────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────┐
│  Hetzner / ArvanCloud VPS (2 Core CPU, 4GB RAM) ~$5-10/mo│
│  ┌────────────────────────────────────────────────────┐  │
│  │ Docker Compose Infrastructure                      │  │
│  │  ├── Nginx (Reverse Proxy & Rate Limiter)          │  │
│  │  ├── Next.js App (Front-End & Workspaces)          │  │
│  │  ├── NestJS API (Back-End Core Gateway)            │  │
│  │  ├── Python OCR Microservice (Tesseract)           │  │
│  │  ├── PostgreSQL (Primary Database)                 │  │
│  │  └── Redis (Session, Cache & BullMQ Queue)         │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

### ویژگی‌های کلیدی این زیرساخت:

- **دامنه و امنیت:** مدیریت DNS، گواهی SSL رایگان و محافظت در برابر حملات DDoS با **Cloudflare**.
    
- **سرویس‌های کانتینری (Docker Compose):** تمام سرویس‌ها به صورت ایزوله اجرا می‌شوند تا انتقال بعدی به سرورهای قوی‌تر (یا Kubernetes) بدون دستکاری در کد انجام شود.
    
- **مدیریت پردازش‌های سنگین:** استفاده از Redis و BullMQ جهت ایزوله‌سازی صف تحلیل OCR و فراخوانی APIهای هوش مصنوعی تا لود سرور اصلی بالا نرود.
    

## 🗓️ ۲. نقشه راه توسعه گام‌به‌گام پروژه (Step-by-Step Roadmap)

```
[ فاز ۱: زیرساخت و لندینگ ] ➔ [ فاز ۲: پنل ممیزی قبض ] ➔ [ فاز ۳: پنل سولار و مهندسی ] ➔ [ فاز ۴: دانشنامه و AI Arena ] ➔ [ فاز ۵: تلگرام و تجاری‌سازی ]
```

### 🔹 گام اول: زیرساخت اولیه، دیتابیس و لندینگ پیج سازمانی (هفته ۱ تا ۲)

- [ ] راه‌اندازی Monorepo یا ساختار مجزای NestJS (Backend) و Next.js (Frontend) در Git.
    
- [ ] طراحی و پیاده‌سازی **Prisma Schema** جامع (کاربران، قبوض، سولار، ابزارها، دانشنامه و AI Settings).
    
- [ ] پیاده‌سازی لندینگ پیج سئومحور Xennic بر اساس **پلت رنگی سازمانی** (پوستر شرکت زر نور نیرو یکتا).
    
- [ ] کانفیگ Docker Compose و استقرار (Deploy) نسخه اولیه روی سرور با Cloudflare.
    

### 🔹 گام دوم: ساخت پنل ممیزی و تحلیل قبض برق (Smart Audit Panel) (هفته ۳ تا ۵)

- [ ] ساخت مایکروسرویس دریافت فایل PDF و عکس قبض و اتصال به موتور OCR.
    
- [ ] پیاده‌سازی فرمول‌های محاسباتی تعرفه‌ها، جریمه راکتیو، دیماند و تجاوز از قدرت.
    
- [ ] طراحی UI پنل ممیزی (`/audit`) و صدور گزارش گرافیکی و فایل PDF قابل چاپ.
    
- [ ] اتصال تحلیل قبض به موتور رایگان GitHub Models جهت تولید راهکارهای مدیریتی AI.
    

### 🔹 گام سوم: پنل محاسبات خورشیدی و ابزارهای مهندسی (هفته ۶ تا ۸)

- [ ] پیاده‌سازی پنل امکان‌سنجی خورشیدی (`/solar`) شامل نقشه، ارزیابی تابش و طرح توجیهی مالی (ماده ۱۲ و ۱۶).
    
- [ ] ساخت ماشین‌حساب‌های پنل مهندسی (`/engineering`): افت ولتاژ، سایزینگ کابل، خازن‌گذاری و ژنراتور بر اساس IEC.
    
- [ ] ساخت ماژول صدور دفترچه محاسبات رسمی PDF با لوگوی شرکت زر نور نیرو یکتا.
    

### 🔹 گام چهارم: ماژول دانشنامه مهندسی و AI Arena (هفته ۹ تا ۱۰)

- [ ] پیاده‌سازی بخش دانشنامه (`/wiki`) برای مقررات ملی ساختمان (مبحث ۱۳)، نشریه ۱۱۰ و آیین‌نامه‌های توانیر.
    
- [ ] ساخت ماژول **Multi-Model AI Gateway** (پشتیبانی از GitHub Models و افزودن API Key اختصاصی - Pro BYOK با رمزنگاری AES-256).
    
- [ ] پیاده‌سازی بخش AI Arena برای مقایسه تحلیل‌های مدل‌های مختلف AI روی اسناد انرژی.
    

### 🔹 گام پنجم: توسعه پنل مدیریت ارشد، تلگرام و درگاه پرداخت (هفته ۱۱ تا ۱۲)

- [ ] پیاده‌سازی **Super Admin Panel** (`/admin`) جهت مدیریت کاربران، تراکنش‌ها، لاگ‌های AI و CMS دانشنامه.
    
- [ ] اتصال درگاه پرداخت و سیستم کیف‌پول اختصاصی برای هر ماژول.
    
- [ ] ساخت ربات تلگرام و **Telegram Mini App** جهت ارائه خدمات سریع ممیزی قبض و محاسبات مهندسی در تلگرام.
