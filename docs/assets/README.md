# docs/assets — منابع باینری مستندات

## قواعد

- همه‌ی تصاویر، نمودارها و فایل‌های ضمیمه‌ی مستندات فقط در این پوشه قرار می‌گیرند.
- ارجاع در اسناد **همیشه با مسیر نسبی** است، مثلاً:

  ```markdown
  ![عنوان](../../docs/assets/file.png)
  ```

- فرمت‌های مجاز: `SVG` (ترجیح)، `PNG`, `WebP`, `JPG` — حداکثر حجم هر فایل: ۲ مگابایت.
- افزودن هر فایل باید با ذکر منبع/مالکیت در همان PR مستند شود.
- **هرگز** از مسیر مطلق (`file:///tmp/...`) استفاده نشود.
