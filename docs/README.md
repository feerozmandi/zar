## قواعد مدیریت اسناد

1. اسناد جدید در `docs/` با نام فارسی توصیفی و شماره‌گذاری منظم ثبت شوند.
2. تصاویر و فایل‌های باینری فقط در `docs/assets/` ذخیره و با **مسیر نسبی** ارجاع شوند (هرگز مسیر `file:///tmp/...` یا مطلق).
3. هر سند در ابتدا دارای: عنوان، مالک، تاریخ و وضعیت باشد.
4. تغییرات اسناد از طریق PR و طبق `CONTRIBUTING.md` وارد شوند.
5. حجم هر فایل باینری حداکثر ~۲ مگابایت؛ تصاویر بهینه (SVG/WebP) ترجیح داده می‌شوند.
